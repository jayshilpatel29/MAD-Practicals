# MAD Practical 1 – Kotlin Programming

## 📱 Mobile Application Development

This practical demonstrates the basic programming concepts of **Kotlin** required for Mobile Application Development (MAD).

## 🎯 Aim

Develop Kotlin programs to demonstrate various programming concepts such as variables, type conversion, input/output, control flow, functions, recursion, arrays, collections, classes, constructors, inheritance, operator overloading, and matrix operations.

---

## 📚 Practical Contents

### 1.1 Store & Display Values in Different Variables
Demonstrates different Kotlin data types:

- Integer
- Double
- Float
- Long
- Short
- Byte
- Char
- Boolean
- String

### 1.2 Type Conversion
Demonstrates type conversion between:

- Integer → Double
- String → Integer
- String → Double

### 1.3 Student Information
Takes student information as input and displays:

- Name
- Enrollment Number
- Branch
- Class
- Other student details

### 1.4 Odd or Even Number
Checks whether a given number is **odd or even** using Kotlin control flow.

### 1.5 Display Month Name
Uses the Kotlin `when` expression to display the month name based on the user's input.

### 1.6 User-Defined Function
Creates a user-defined function to perform:

- Addition
- Subtraction
- Multiplication
- Division

### 1.7 Factorial Using Recursion
Calculates the factorial of a number using a recursive function.

Example:

```text
5! = 5 × 4 × 3 × 2 × 1 = 120
```

### 1.8 Working with Arrays
Demonstrates:

- `Arrays.deepToString()`
- `contentDeepToString()`
- `joinToString()`
- `range`
- `downTo`
- `until`
- Array traversal
- Sorting without built-in functions
- Sorting using built-in functions

### 1.9 Maximum Number from ArrayList
Finds the maximum value from an `ArrayList` of integers.

### 1.10 Classes and Constructors
Creates a `Car` class with properties such as:

- Type
- Model
- Price
- Owner
- Miles Driven

The program demonstrates constructors, functions, original price, current price, and displaying car information.

### 1.11 Operator Overloading and Matrix Operations
Creates a `Matrix` class and demonstrates:

- Operator overloading
- Matrix addition
- Matrix subtraction
- Matrix multiplication
- `toString()` function overloading/customization

- Perform type conversion.

- Use conditional statements and `when`.

- Understand recursion.
- Work with arrays and ArrayLists.
- Implement sorting algorithms.
- Create classes and constructors.
- Understand inheritance.
- Use primary and secondary constructors.
- Implement operator overloading.
- Perform matrix operations in Kotlin.
